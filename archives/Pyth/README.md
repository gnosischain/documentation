# Pyth on Gnosis (Archived)

:::danger Archived
Pyth **no longer supports Gnosis Chain or Chiado**. Its Pyth Core contracts on both networks were not upgraded on 26 August 2026, and Pyth now lists both networks as having [no supported Pyth contract](https://docs.pyth.network/pro/no-longer-supported). Do not use the Pyth contracts listed in these pages.

The pages in this folder are kept for historical reference only and are not published on [docs.gnosischain.com](https://docs.gnosischain.com).
:::

Pyth is a first-party oracle network with a pull design: a contract posts a signed price update on-chain when it needs a price. This page documented how to read Pyth price feeds from Solidity on Gnosis Chain and Chiado, and listed the Pyth contract addresses on both networks.
