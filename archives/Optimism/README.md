# Optimism on Gnosis (Archived)

:::danger Archived
Optimism on Gnosis is **no longer part of Gnosis Chain**. The network (chain ID 300) was deprecated in March 2023.
Do NOT deposit funds into the bridge contracts listed in these pages, they will not be withdrawable.

The pages in this folder are kept for historical reference only and are not published on [docs.gnosischain.com](https://docs.gnosischain.com).
:::

Optimism on Gnosis was an Optimism (OVM) implementation in which Gnosis functioned as the L1 — the role Ethereum plays for Optimism Mainnet — and Optimism on Gnosis as the L2. Deployment followed the standard Optimism flow with configs adjusted for the Gnosis Chain setup.
