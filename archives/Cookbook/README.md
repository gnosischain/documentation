# Using Cookbook (Archived)

:::danger Archived
Cookbook, a smart contract marketplace, **is no longer online**: cookbook.dev no longer resolves. Do not follow links to it, because a lapsed domain can be re-registered by anyone.

The pages in this folder are kept for historical reference only and are not published on [docs.gnosischain.com](https://docs.gnosischain.com).
:::

Cookbook was an open source smart contract marketplace. From its web interface you could search for a Solidity contract, configure it and deploy it to Gnosis Chain or Chiado.
