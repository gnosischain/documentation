# Using Cookbook (Archived)

:::danger Archived
Cookbook is **no longer a supported way to deploy contracts on Gnosis Chain**. cookbook.dev has gone offline: as of October 2026 the domain no longer resolves, so the marketplace and deploy flow documented here can no longer be used.

The page in this folder is kept for historical reference only and is not published on [docs.gnosischain.com](https://docs.gnosischain.com).
:::

Cookbook was an open source smart contract marketplace for searching, downloading and deploying Solidity contracts, with support for Gnosis Chain and Chiado. The page in this folder walked through finding a contract on the marketplace and deploying it with Cookbook's "Simply Deploy" flow.

Not to be confused with the "Ask Cookbook" AI assistant (`@cookbookdev/docsbot`), a separate Cookbook product that was embedded in these docs from September 2024 until it was removed in January 2026.
