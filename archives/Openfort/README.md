# Openfort (Archived)

:::danger Archived
Openfort **does not support Gnosis Chain**: its [supported chains](https://www.openfort.io/docs/configuration/chains) include neither Gnosis Chain nor Chiado.

The pages in this folder are kept for historical reference only and are not published on [docs.gnosischain.com](https://docs.gnosischain.com).
:::

Openfort is a wallet infrastructure provider. This page described its embedded wallets and smart accounts for apps on Gnosis Chain.
