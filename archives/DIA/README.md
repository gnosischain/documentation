# DIA (Archived)

:::danger Archived
DIA **has no maintained oracle on Gnosis Chain**: the Gnosis Chain oracle it announced stopped updating in July 2025, and its [Gnosis Chain guide](https://www.diadata.org/docs/guides/chain-specific-guide/gnosis-chain) lists no contracts.

The pages in this folder are kept for historical reference only and are not published on [docs.gnosischain.com](https://docs.gnosischain.com).
:::

DIA is a cross-chain oracle network that sources trade data directly from markets. This page described DIA's data products on Gnosis Chain and how to request a custom oracle.
