# Using Truffle with Gnosis (Archived)

:::danger Archived
Truffle is **no longer a supported way to build on Gnosis Chain**. Consensys [announced the sunset of Truffle and Ganache](https://consensys.io/blog/consensys-announces-the-sunset-of-truffle-and-ganache-and-new-hardhat) in 2023; the toolchain receives no further maintenance or security updates, and its documentation is frozen at [archive.trufflesuite.com](https://archive.trufflesuite.com/).

The pages in this folder are kept for historical reference only and are not published on [docs.gnosischain.com](https://docs.gnosischain.com).
:::

Truffle was a development environment used for smart contract compiling, deploying, testing and debugging. These pages documented Truffle's `truffle-config.js` network entries for Gnosis (chain ID 100) and Chiado (chain ID 10200), and the `truffle-plugin-verify` flow for verifying sources on Gnosisscan.
