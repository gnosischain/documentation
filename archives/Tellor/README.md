# Tellor (Archived)

:::danger Archived
Tellor **no longer lists Gnosis Chain**: its [contracts reference](https://docs.tellor.io/tellor/using-tellor-data/contracts-reference) covers only Ethereum, Sepolia and Base. Do not build on Tellor data feeds on Gnosis Chain.

The pages in this folder are kept for historical reference only and are not published on [docs.gnosischain.com](https://docs.gnosischain.com).
:::

Tellor is a decentralized oracle protocol in which reporters stake tokens to submit data that anyone can dispute. This page documented reading Tellor data feeds from a contract on Gnosis Chain.
