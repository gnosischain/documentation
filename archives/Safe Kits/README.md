# Safe Auth Kit and Relay Kit with Gelato (Archived)

:::danger Archived
These guides are built on parts of the Safe Core SDK that no longer work: Safe **removed Auth Kit in September 2024**, and since 1 September 2026 **Relay Kit no longer relays transactions through Gelato**. For current Safe integrations on Gnosis Chain, see [Account abstraction with Safe](https://docs.gnosischain.com/technicalguides/account-abstraction/Safe%20and%20supported%20AA%20infra%20providers).

The pages in this folder are kept for historical reference only and are not published on [docs.gnosischain.com](https://docs.gnosischain.com).
:::

Both guides were part of the Safe section of the account abstraction tutorials.

## Archived pages

- [Generate your Safe Smart Account](./integration-guide-for-safe.md) — creating a Safe with Auth Kit and Protocol Kit, then executing a transaction
- [Building on Safe AA with Gelato](./gelato.md) — gasless Safe transactions through Relay Kit and Gelato 1Balance or SyncFee
