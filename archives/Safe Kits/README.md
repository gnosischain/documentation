# Safe account abstraction guides (Archived)

:::danger Archived
These pages are built on SDK features that no longer work: Safe **removed Auth Kit in September 2024**, since 1 September 2026 **Relay Kit no longer relays transactions through Gelato**, and **permissionless.js has removed the APIs** the Pimlico guide uses. For current Safe integrations on Gnosis Chain, see [Account abstraction with Safe](https://docs.gnosischain.com/technicalguides/account-abstraction/Safe%20and%20supported%20AA%20infra%20providers).

The pages in this folder are kept for historical reference only and are not published on [docs.gnosischain.com](https://docs.gnosischain.com).
:::

These pages made up the Safe section of the account abstraction tutorials.

## Archived pages

- [Building Account Abstraction with Safe](./account-abstraction-with-safe.md) — the section overview, covering the Safe Core Account Abstraction SDK kits
- [Generate your Safe Smart Account](./integration-guide-for-safe.md) — creating a Safe with Auth Kit and Protocol Kit, then executing a transaction
- [Building on Safe AA with Gelato](./gelato.md) — gasless Safe transactions through Relay Kit and Gelato 1Balance or SyncFee
- [Building on Safe AA with Pimlico](./pimlico.md) — a Safe account sending ERC-4337 user operations through Pimlico with permissionless.js
