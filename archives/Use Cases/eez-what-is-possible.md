# What is possible on Gnosis EEZ

Every L2 so far has been a bridge away from the assets, liquidity and price feeds on Ethereum mainnet. Gnosis EEZ will close that gap with synchronous composability: a contract on Gnosis EEZ will be able to call a contract on Ethereum mainnet and use the result in the same transaction, and if any step fails, the whole transaction reverts. Apps will keep fast blocks and low fees, and reach mainnet depth when they need it. At launch, calls will run from Gnosis EEZ into Ethereum, with the reverse direction and nested calls following in 2027, as set out in [how it works](/eez/how-it-works).
