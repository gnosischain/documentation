# Using Web3.js (Archived)

:::danger Archived
ChainSafe **sunset web3.js on 4 March 2025** and archived the [web3.js repository](https://github.com/web3/web3.js), so the library no longer receives updates. Use [viem](https://viem.sh) or [ethers.js](https://docs.gnosischain.com/developers/Interact%20on%20Gnosis/ethers-js) instead.

The pages in this folder are kept for historical reference only and are not published on [docs.gnosischain.com](https://docs.gnosischain.com).
:::

web3.js is a JavaScript library for interacting with Ethereum-compatible nodes over HTTP, IPC or WebSocket. This page showed how to install it and use it with Gnosis Chain.
