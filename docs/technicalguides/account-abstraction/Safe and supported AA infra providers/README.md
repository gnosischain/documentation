# Safe

Safe smart accounts are deployed on Gnosis Chain. [Safe's documentation](https://docs.safe.global/) covers building with them:

- [Safe SDK](https://docs.safe.global/sdk/overview): deploy Safe accounts and send transactions from your app.
- [ERC-4337](https://docs.safe.global/advanced/erc-4337/overview): use a Safe with bundlers and paymasters.
