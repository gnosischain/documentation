## Before you build

The demos run on local chains and on the Chiado testnet, against the same early-stage contracts described in [How it works](/eez/how-it-works). They are for learning the protocol, not for deploying to production. The [timeline](/eez/timeline) tracks when Gnosis EEZ goes live.
