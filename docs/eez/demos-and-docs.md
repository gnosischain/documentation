# EEZ demos and protocol docs

This documentation covers Gnosis EEZ, the first instance of the Ethereum Economic Zone. The EEZ framework itself has its own documentation and a set of hands-on demos, maintained by the EEZ Association.

## EEZ resources

- **[EEZ protocol docs](https://docs.eez.io/)**: the specification, covering execution and static entries, multi-prover verification, limits and boundaries, and the blob format.

## Learn about the EEZ

- **[EEZ demos](https://build.eez.io/)**: hands-on walkthroughs that follow one call from one chain to another and back in the same transaction, with real protocol code. They are grouped by who you are: dapp developers, rollup operators and protocol researchers.

## Before you build

The demos run on local chains and on the Chiado testnet, against the same early-stage contracts described in [How it works](/eez/how-it-works). They are for learning the protocol, not for deploying to production. The [timeline](/eez/timeline) tracks when Gnosis EEZ goes live.
