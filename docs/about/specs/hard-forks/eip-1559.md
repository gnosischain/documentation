# EIP-1559

## When EIP-1559

:::success EIP-1559 is live on Gnosis.

* **Network**: Gnosis
* **Date Implemented**: November 12, 2021
* **Block number**: `19,040,000`
:::

## What is EIP-1559

EIP 1559 introduces a `BASEFEE` for all blockchain transactions. This is a minimum fee charged for each transaction, and it is adjusted depending on network congestion (gas usage per block). When gas usage is high, the fee increases, and when it is low, the fee decreases.

In addition to the base fee, a transaction can add a priority fee, a tip that goes to the block proposer to incentivize them to include it in a block.

## How 1559 impacts the Gnosis

On Ethereum the base fee is burned. On Gnosis it is not: the chain spec sends the base fee to a fee collector address instead, starting from the same block EIP-1559 activated. Tips still go to the block proposer.

| Network | Fee collector | From |
| --- | --- | --- |
| Gnosis | [`0x6BBe78ee9e474842Dbd4AB4987b3CeFE88426A92`](https://gnosisscan.io/address/0x6BBe78ee9e474842Dbd4AB4987b3CeFE88426A92), a Safe | Block 19,040,000 |
| Chiado | `0x1559000000000000000000000000000000000000` | Genesis |

The settings are `eip1559FeeCollector` and `eip1559FeeCollectorTransition` in each network's `genesis.json` in the [configs repo](https://github.com/gnosischain/configs). Because the base fee is collected rather than burned, it does not reduce the supply of xDai, which is backed by the DAI and USDS locked in the [xDai bridge](/bridges/About%20Token%20Bridges/xdai-bridge) on Ethereum.

**Block size is also increased to 34M with this upgrade.**
