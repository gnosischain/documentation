# Oracle Providers

Oracles bring off-chain data - like price feeds - on-chain so smart contracts on Gnosis Chain can use it.

- [Chainlink](/tools/Oracle%20Providers/chainlink) - aggregated price feeds and external data via a decentralized oracle network.
- [API3](/tools/Oracle%20Providers/api3) - first-party oracles with Oracle Extractable Value (OEV) recapture.
- [Chronicle](/tools/Oracle%20Providers/chronicle) - decentralized, scalable and cost-efficient oracles.
- [Gas Price](/tools/Oracle%20Providers/gas-price) - recommended gas prices from node fee methods and the Blockscout gas price oracle.
